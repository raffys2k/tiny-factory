🚀 Quick Start

First Time Setup

Step 1: Power on your Tinytrader device
Step 2: Connect your phone/computer to WiFi network: Tinytrader-Setup
Password: 12345678
Step 3: Open browser and go to http://192.168.4.1
Step 4: Select your home WiFi, enter password, click Connect
Step 5: After reboot, connect to your home WiFi and go to http://tinytrader.local
💡 Tip: The device remembers your WiFi. Next time it will connect automatically.

🎯 Trading Modes

🟢 DRY Mode

  • No real money involved
  • Uses virtual balance
  • Perfect for testing strategies
  • Safe way to learn the system

🔴 LIVE Mode

  • Uses your real funds
  • Connects to exchange account
  • Requires API keys
  • Start with small amounts
💡 Tip: Always test in DRY mode first before going LIVE!

🔑 Exchange API Keys

Getting Your Keys

1. Log in to your Coins.ph account
2. Go to Settings → API Management
3. Create a new API key with "Trade" permissions
4. Save your API Key and Secret Key
⚠️ Important: Keep your keys secure! Never share them.

Entering Your Keys

1. Click the "SET" button on dashboard
2. Find the "Exchange" section
3. Enter your API Key and Secret Key
4. Click "Save"

📝 Trading Rules

How Rules Work

Rules tell the bot when to buy. Each rule compares two things:

IF [Something] IS [Greater/Less] THAN [Something Else]

Simple Example

BUY when RSI is less than 30

Meaning: buy when the market is "oversold" (due for a bounce)

Building a Rule

1. Click "RULES" button
2. Choose left side (indicator, number, or price)
3. Choose operator (>, <, or =)
4. Choose right side (indicator, number, or price)
5. Choose logic (AND = both true, OR = either true)
6. Click "Save Rules"

🪙 Selecting Coins to Trade

What Are Trading Pairs?

These are the cryptocurrencies you want to trade, priced in PHP:

  • BTCPHP = Bitcoin
  • ETHPHP = Ethereum
  • DOGEPHP = Dogecoin
  • and many more...

How to Choose

1. Click "PAIRS" button
2. Check the boxes next to coins you want
3. Optionally add custom pairs
4. Click "Save Selected"
💡 Recommendations for beginners:
  • Start with 3-5 pairs maximum
  • Include at least one major coin (BTC, ETH)
  • Avoid very volatile coins initially

🛡️ Safety & Risk Management

Built-in Safety Features

  • Max Active Trades: Limits how many trades can be open at once
  • Max Pairs: Limits how many coins are monitored
  • Stop-Loss: Limits losses (configurable)
  • Take-Profit: Locks in profits automatically
  • DRY Mode: Practice without risk
  • Spread Filter: Avoids trading during wide spreads
  • Entry Schedule: Prevents trading at risky times
⚠️ Important: No trading system is risk-free. Start small and test thoroughly.

Best Practices

  • Always test new rules in DRY mode first
  • Start with small stakes
  • Monitor your bot regularly
  • Keep your API keys secure
  • Update rules based on market conditions

❓ Frequently Asked Questions

Why aren't any trades opening?

  • Check if trading is STARTED (green button)
  • Verify you've set up rules
  • Make sure you've selected at least one trading pair
  • Check if the schedule allows trading
  • Ensure you have enough balance

What's the difference between LIVE and DRY?

  • DRY: Paper trading, virtual money only
  • LIVE: Real money, connects to your exchange account

Can I run this 24/7?

  • Yes, the bot is designed for continuous operation
  • It automatically reconnects if WiFi drops
  • Use the schedule feature to control trading hours

What happens if the power goes out?

  • All trades are saved automatically
  • The bot recovers its state when power returns
  • You can monitor and restart from the dashboard

How do I reset everything?

  • Click the "RESET" button on the dashboard
  • This clears all settings and trades
  • The device will restart automatically
