STEP 2

🔌 Power Up

Connect the power and wait for the device to start.

📋 Instructions

  1. Connect the USB-C cable to the tiny Radio device.
  2. Plug the other end into a power adapter (5V, 1A or higher).
  3. Wait about 10–15 seconds for the device to start up.
  4. The device will automatically enter setup mode if no WiFi is configured.
💡 Tip: This is normal for first-time use. The device is waiting for you to configure WiFi.

📱 Setup with the Android App

  1. Download and install the tiny Radio app from the button above.
  2. Open your phone/tablet's WiFi settings.
  3. Connect to TinyRadio AP (no password).
  4. Open the tinyRadio android application.
  5. Click "Scan Networks" or Enter your WiFi name and password in the app.
  6. Tap "Save & Reboot" — the app handles the rest!
  7. In case the android application doesnt automatically refresh.
    1. Exit the tinyRadio android application
    2. Clear recents or clear tinyRadio application data
    3. Open the tinyRadio application again.
✨ Done! The device will connect to your WiFi on reboot and start playing.

🌐 Setup with Web Browser

  1. Open your phone/computer's WiFi settings.
  2. Connect to TinyRadio AP (no password).
  3. Open your web browser and go to 192.168.4.1.
  4. Click "Scan Networks" or enter your WiFi name.
  5. Enter your WiFi password and click "Save & Reboot".
💡 Tip: The device only supports 2.4 GHz WiFi networks. If your router has both bands, connect to the 2.4 GHz one.
⚠️ Important: After saving WiFi credentials, the device will reboot. This takes about 30 seconds. Please wait — don't unplug the device.

STEP 5

🎛️ Explore & Enjoy

You're all set! Here's what you can do with your tiny Radio.

🎯 Quick Controls

  • Change stations: Use the app or web dropdown.
  • Adjust volume: Use the + and - buttons.
  • Set EQ: Boost bass, mid, or treble to your liking.
  • Schedule playback: Set up daily profiles for automatic listening.

🔄 Updating Your Station List

Your radio comes with a curated list of stations, but you can update it anytime from the Device page in the web interface.

  1. Open the Device page.
  2. Tap Check for Updates to see if a newer list is available.
  3. If an update is available, tap Update Now.
  4. Wait a few seconds — you'll see a confirmation message.
💡 Undo an update: Every update is backed up automatically. If you don't like the new list, tap Revert to Previous List on the Device page to restore the previous one. This button is only enabled when a backup is available.
✨ Safe by design: If an update fails, the device automatically restores the previous station list. You will never be left with no stations.

🔧 Advanced Features

  • Equalizer Presets: Flat, Bass Boost, Vocal, Treble, Rock, Warm
  • Daily Schedules: Set start/end times, station, volume, and days
  • Device Management: Reboot, factory reset, and diagnostics
  • Auto-Reconnect: Device reconnects to WiFi automatically

🆘 Need Help?

  • Use the Diagnostics page in the web interface
  • Factory reset from the web interface if you need to start over
  • Check the quick start card included in the box
💡 Pro Tip: The Android app makes it easy to control your radio directly from your phone or tablet.
🎉 Setup Complete! Your tiny Radio is ready. Happy listening! 📻
