🎯 About

tinyRadio is an internet radio player that streams from a curated list of 500+ stations worldwide. It's designed to be simple, reliable, and easy to use.

The station list is periodically updated and maintained, each station passes through a set of tests and checks before getting considered.

🚀 Getting Started

  1. Power on the device — it will automatically try to connect to WiFi.
  2. If no WiFi is configured, the device will start in setup mode.
  3. Follow the guide from this link on how to setup your radio
  4. Once connected, the radio will start playing from the last station.
  5. Access the web interface from any browser on the same network.
🔒 Note: The web interface is only accessible from your local network. It is not exposed to the internet.

🎛️ Audio Controls

  • Volume: Adjustable from the web interface
  • Equalizer: Bass, Mid, and Treble control
  • Presets: Quick EQ profiles (Flat, Bass Boost, Vocal, etc.)

⏰ Daily Scheduling

The Profiles feature lets you schedule station playback at specific times. Each schedule includes:

  • Start and end time
  • Station selection
  • Volume level
  • Days of the week

The device automatically prepares for scheduled playback to ensure smooth operation. Can work like an alarm clock or an automated player.

🔄 Station Updates & Revert

Your station list can be updated manually from the Device page. Before any update runs, the current list is automatically backed up on the device.

  • Check for Updates: Asks the server if a newer station list is available.
  • Update Now: Downloads and applies the new list.
  • Revert to Previous List: Restores the previous station list — useful if a new update contains stations that don't work for you.

If an update fails partway through, the device automatically restores the previous list — you will never be left with no stations.

🔒 Security Overview

The tiny Radio is designed with security in mind. Here's how your device and network are protected:

🏠 Local Only
The web interface is only accessible from your local network. No remote access is enabled by default.
🔑 No Default Credentials
The device uses your WiFi credentials. No hardcoded passwords exist.
📡 Encrypted WiFi
Supports WPA2 WiFi encryption for secure network communication.
🔄 Secure Updates
Station list updates are fetched over HTTPS from trusted sources. No automated updates without user consent.
🧹 Factory Reset
A factory reset clears all settings, including WiFi credentials.
🛡️ Minimal Attack Surface
The device runs only essential services. No unnecessary open ports.
⚠️ Best Practice: Keep your WiFi network secure with a strong password. The device is only as secure as your home network.

🛡️ User Responsibility

  • Use a strong WiFi password to protect your network
  • Keep the device safe from fall or water damage
  • Perform a factory reset before disposing of the device
  • Contact support if you suspect any security issues

🛠️ Common Issues

No WiFi connection

  • The device will enter setup mode automatically if no WiFi keys are found.
  • Check that your WiFi network is 2.4 GHz (5 GHz is not supported).
  • Ensure the WiFi password is correct.

No audio / station not playing

  • Try a different station — some stations may be temporarily offline.
  • Check the volume level in the web interface.
  • Check if Enable Profiles is active. Radio maybe outside scheduled time.
  • Check if the radio is paused.
  • Ensure that internet connection is active.

Web interface not loading

  • Make sure your device is on the same network as the radio.
  • Check the device IP address from your router's DHCP list and connect directly to the IP.
  • Try using http://tinyradio.local on your browser.

Station Update fails

  • If the update fails, the device automatically restores the previous station list — your stations will not disappear.
  • Reboot tinyRadio. Check diagnostics for Manifest, verify version changed.
  • Always clear application data of tinyRadio's android app if station update doesnt show any changes.
  • If the update succeeded but the new stations don't work for you, use Revert to Previous List on the Device page to roll back.

Station list looks wrong after an update

  • Open the Device page in the web interface.
  • Tap Revert to Previous List to restore the previous station list.
  • This is available whenever a backup exists (it will be greyed out if there is nothing to revert to).

Reset the device

  • Use the Factory Reset option in the web interface.
  • This clears all settings and WiFi credentials.
  • After reset, the device will enter setup mode.

💡 Tips

  • The device uses LED indicators to show status:
    • Short, Rapid Blue blinks: Normal operation
    • Short, Rapid Red blinks: Setup mode or error
    • Short, Rapic Purple blinks: Action in progress
  • For best performance, place the device within range of your WiFi router.
  • Stations are manually updated — User has total control.
  • A backup of the previous station list is kept on the device after every update, so you can always roll back.
